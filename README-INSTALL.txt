ADN - Nuvio Perfect Collection

UPLOAD THESE 6 FILES TO THE ROOT OF:
Novastream1/nuvio-adn

1. adn-cover.webp
2. adn-focused.webp
3. adn-title.png
4. adn-backdrop.webp
5. AIOMetadata-ADN-Catalogs.json
6. Nuvio-ADN-Collection.json

Then:
- Import AIOMetadata-ADN-Catalogs.json in AIOMetadata > Catalogs > Import
- Save AIOMetadata
- Import Nuvio-ADN-Collection.json in Nuvio Collections
- Choose MERGE BY MATCHING IDs
- DO NOT choose Replace on your main profile
